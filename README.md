# micronuclei-detection
Detecting micronuclei in images using Transformer Networks

## Run the best model
- Step1: Put `dataset_v2` folder under microdet
- Step2: make sure that `OUTPUT_DIR` in `run_the_best_experiment.py` exists under dataset_v2
- Step3: `python run_best_experiment.py imidx`, output files will be stored under the `DIRECTORY + OUTPUT_DIR'
